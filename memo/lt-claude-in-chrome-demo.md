## 0. 一言でいうと

- **URLだけ渡して「遊んで、改善点を出して」と頼んだら、約14分でゲームを読み解き、冒険者を組んで1位をとり、UIの改善点を10件出してきた。**
- 私が渡したのは、ローカルで動いているゲームのURLと、数行の日本語だけ。ゲームの仕様・正解・資料の読み方は一切教えていない。
- 操作は Claude in Chrome（Chromeの拡張機能）で、**私のMacのChromeを実際にクリック・入力して**進めた。

## 3. Claudeが画面から読み取って判断したこと（1回目）

ゲームの説明はしていないので、すべて画面の文章から判断している。

1. **ルールの把握**: 募集要項を読み、「登録 → 依頼書 → 準備（重さ80まで）→ 試走 → 送り出し → 講評」という流れと、「送り出し1日2回・試走3回」という制限を把握。
2. **資料室24本の読み分け**: 図鑑や生還者の手記などは正しい情報、言い伝え・酒場の噂・道具屋の売り文句は**ひっかけ**（にんにく、聖水、窓を開ける、杯を飲む）と判断。
3. **虫食いの呪文を復元**: 大魔法の写本の欠けた7か所を、子守歌・従軍記・鐘の銘・村の暦など**別々の資料7本**から拾って埋めた（例: 「二百の■■を啜りし」→ 村の暦にある「霜夜」）。
4. **持ち物の取捨選択**: 道具8つから役に立つ3つ（日誌・手鏡・燭台）だけを選び、にんにく・聖剣・お守りなどのダミーは置いていった。
5. **巻物（スキル）を自作**: 「紋→聖句」21種、「血の秘術→破り方」12種、「呪文の全7節」を資料から書き起こした。
6. **結界（ガードレール）の言葉選び**: 敵の決まり文句5つを選び、**仲間の本物の声や呪文の一節は消さない**言葉にした。
7. **試走で自分の失敗を見つけて直した**: 1回目の試走は2/3。記録を読んで「手鏡が実は持ち物に入っていなかった」ことを自分で突き止め、直して3/3にしてから本番に出した。

## 4. 改善提案の例（実際にゲームへ反映したもの）

1回目に出た提案から、翌日までに直したもの（3回目で反映を確認）:

| Claudeの指摘 | 改善後 |
| --- | --- |
| 送り出し完了の画面が閉じられない | Escで閉じられるように |
| 講評の称号が別のボス（竜）のまま | ボスに依存しない称号に |
| 資料24本を1本ずつ開くのが大変 | 「すべて開く」ボタン |
| 巻物・心得の重さが分かりにくい | 「→ 重さ13（30トークンごとに1）」と換算を表示 |
| 試走結果が準備画面を覆う | 左パネルのタブに移動 |
| 送り出す前に持ち物を確認したい | 確認画面に持ち物一覧 |

3回目で新しく見つかった重要な問題: **準備の下書きがブラウザに1つのキーで保存されていて、ログアウトしても消えず、別アカウントで入ると前の人の心得がそのまま見える**（共用PCでの情報漏れ）。

## 6. 注意・補足

- 「約14分」は、依頼を受けてから最終報告までの実時間。ブラウザ操作とClaudeの考える時間の合計。
- 3回目の途中で、パスワード管理の拡張機能が画面を覆ってClaudeが操作できなくなり、私に報告して止まった（約1分）。新しいタブを開き直して自力で再開。
- 資料の全文を読むときは、画面のクリックではなくページの文字を直接読み取っている。録画GIFに映っていない操作もある。
- 戦果は同じ構成でも100%と95.9%で揺れた（AIの判断は毎回少し揺れる）。
- 【要確認】GIFには資料の正解（聖句名・呪文）が映るコマがある。社外や参加予定者に見せる場合は、ネタバレになるコマを外す。
